
# QuantLab Fixed-Income Engineering Platform

A quantitative engineering platform focused on fixed-income
instrument modelling, bond pricing, interest-rate curve
construction and portfolio risk analytics.

## Objectives

- Develop a reliable fixed-income pricing library.
- Implement financial mathematics using Python.
- Build performance-critical components in C++20.
- Integrate Python and C++ using pybind11.
- Develop interest-rate risk and portfolio analytics.
- Establish reproducible testing and numerical validation.

## Technology Stack

- Python
- C++20
- NumPy and SciPy
- pandas
- PostgreSQL
- CMake
- pybind11
- pytest and Hypothesis
- Docker
- GitHub Actions
